# Aim Assist Mod для Minecraft

Мод для Fabric с функцией автоприцеливания.

## Использование
- Нажми **R** для включения/выключения aim assist
- Мод автоматически целится в ближайшего моба или игрока

## Сборка
JAR автоматически собирается через GitHub Actions.

### Получить JAR:
1. Перейди в раздел **Actions** на GitHub
2. Выбери последний запуск workflow
3. Внизу страницы скачай артефакт `aim-assist-mod`

### Локальная сборка:
```bash
./gradlew build
